# JSON Safe-Integer Fungi Conversion Implementation Plan

**Goal:** Admit and prove only the JSON package's two private safe-integer
predicates as package-owned `.fungi` twins through canonical execution and
physical SLIDE/VOK, without switching or retiring TypeScript.

**Architecture:** Upgrade the conversion queue to conserve file-level state
while recording exact symbol candidates. Add two pure, bounded integer flows,
bind them to the private TypeScript source and public JSON validators, then
compile the exact bytes into a physical `.slide` and re-admit through VOK.

## Constraints

- [ ] Keep all 1,449 executable-family paths in the file-level denominator.
- [ ] A scoped decision must not authorize its file or sibling symbols.
- [ ] Preserve JavaScript safe-integer and positive/non-negative boundaries.
- [ ] Refuse floats, NaN-like values, infinities and wide integers rather than
  coercing them.
- [ ] Use no null, NaN value, `else if`, exception syntax, `for`, `while` or
  `loop`.
- [ ] Add no effect, capability, contract permission, Hallmark, border grant,
  global vault access or host API.
- [ ] Keep TypeScript and all consumers active.
- [ ] Commit locally only; do not push.
- [ ] Do not run full tooling, `graph-all`, normal phase-close or monolithic
  memory evaluation.
