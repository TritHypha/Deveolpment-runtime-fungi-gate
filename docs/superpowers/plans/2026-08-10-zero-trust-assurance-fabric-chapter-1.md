# Zero-Trust Assurance Fabric Chapter 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a non-authorizing Chapter 1 assurance host that admits closed manifests, preserves unsafe boundary state, emits typed observations, derives exact-subject Signet/Wax Seal reference evidence, and compares itself with the existing phase-close runner without replacing that runner.

**Architecture:** Add focused ESM modules under `scripts/lib/assurance-fabric/` and keep `scripts/run-phase-close.mjs` as the sole live authority throughout this chapter. The candidate host runs only through a separate explicit shadow CLI, reuses the existing owned-process-tree boundary, and produces `authorizing: false` reports. A `.fungi` linter correction first restores trustworthy `unsafe let` evidence; the JavaScript host then implements the exact `boundary-untrusted` bootstrap equivalent required by the design.

**Tech Stack:** Node.js ESM, `node:test`, built-in `node:crypto`, built-in `TextDecoder`, existing `scripts/lib/owned-process-tree.cjs`, TypeScript compiler package tests, Galerina `.fungi` strict checker.

## Global Constraints

- The approved design is `docs/superpowers/specs/2026-08-10-zero-trust-assurance-fabric-design.md`.
- Keep `scripts/run-phase-close.mjs` authoritative; Chapter 1 must not create the live `governance/phase-close-commands.json` file or change a phase-close verdict.
- Every Chapter 1 report and Wax Seal must contain `authorizing: false` and must grant no conversion, SLIDE, signing, publication, production, retirement or release authority.
- Analyzer output, child stdout/stderr, environment input, consultant output and generated bytes enter through an opaque boundary-untrusted handle.
- Analyzer schemas have codomain `{-1, 0}`; any supplied `+1`, `allow`, `pass`, `authorizing`, `null`, NaN, surplus field or unknown tag refuses.
- Preserve the independent Tri-1 coordinates `D` data trust, `C` component assurance and `A` execution authority; authorize only when `min(D, C, A) = +1`.
- Use precise states: `0` is untrusted, `-1` is distrusted, and `+1` is assured only for the exact named context.
- The Signet remains private process-local state. A component, serialized record or copied object cannot mint a decision, admitted handle, lease or sink capability.
- A Wax Seal is a terminal, value-only, non-authorizing receipt. It proves exact binding/integrity only and cannot be presented back as live authority.
- Domain records contain no `null`, `undefined`, NaN or infinite number. Optional fields use explicit `{ kind: "absent", reason }` or `{ kind: "present", value }` variants.
- All schemas are closed; unknown fields, duplicate IDs, root escape, dependency cycles, empty required arrays and unsafe numeric values refuse.
- Child execution uses `runOwnedProcessSync`; do not add direct `spawnSync`, shell execution or ambient command construction.
- Do not add external dependencies, production keys, signatures or network calls.
- Use codebase-memory first for code discovery and Myco for literal corpus lookup; do not introduce raw glob/grep-based discovery.
- Tracked documents contain repository-relative paths only. Memory remains a routing index, not an evidence warehouse.
- Each task uses red-green TDD and ends in its own local commit. Do not push.

- [ ] **Step 3: Implement the exact closed model**

Create the module with these exports and rules:

```js
import { types as utilTypes } from "node:util";

export const TRIT = Object.freeze({
  DISTRUSTED: -1,
  UNKNOWN: 0,
  ASSURED: 1,
});

export const RESULT_TAG = Object.freeze({
  BLOCKING_PASS: "BLOCKING_PASS",
  BLOCKING_FAIL: "BLOCKING_FAIL",
  UNKNOWN: "UNKNOWN",
  ADVISORY_FINDINGS: "ADVISORY_FINDINGS",
  INFORMATIONAL: "INFORMATIONAL",
  NOT_APPLICABLE: "NOT_APPLICABLE",
  REFUSED: "REFUSED",
  LEGACY_EXIT: "LEGACY_EXIT",
});

export const SOURCE_CLASS = Object.freeze({
  ANALYZER: "analyzer",
  HOST: "host",
  LEGACY_EXIT: "legacy-exit",
});

const TRITS = new Set(Object.values(TRIT));
const TAGS = new Set(Object.values(RESULT_TAG));
const SOURCES = new Set(Object.values(SOURCE_CLASS));
const EXACT_KEYS = Object.freeze(["detail", "sourceClass", "subjectId", "tag", "trit"]);

export function foldRequiredTrits(values) {
  if (!Array.isArray(values) || values.length === 0) {
    throw new TypeError("required trits must be a non-empty array");
  }
  if (values.some((value) => !TRITS.has(value))) {
    throw new TypeError("every value must belong to the closed trit domain");
  }
  return Math.min(...values);
}

export function makeAssuranceResult(input) {
  if (!input || typeof input !== "object" || Array.isArray(input) || utilTypes.isProxy(input)) {
    throw new TypeError("result must be an exact ordinary object");
  }
  const keys = Object.keys(input).sort();
  if (keys.length !== EXACT_KEYS.length || keys.some((key, index) => key !== EXACT_KEYS[index])) {
    throw new TypeError("result fields must match the closed schema");
  }
  if (!TAGS.has(input.tag) || !TRITS.has(input.trit) || !SOURCES.has(input.sourceClass)) {
    throw new TypeError("result tag/trit/source class is invalid");
  }
  if (![input.sourceClass, input.subjectId, input.detail]
    .every((value) => typeof value === "string" && value.length > 0)) {
    throw new TypeError("result strings must be non-empty");
  }
  if (input.sourceClass === SOURCE_CLASS.ANALYZER
      && (input.tag === RESULT_TAG.BLOCKING_PASS || input.trit === TRIT.ASSURED)) {
    throw new TypeError("BLOCKING_PASS and +1 are host-derived only");
  }
  return Object.freeze({ ...input });
}

export function isBlockingFailure(result) {
  return result.tag === RESULT_TAG.BLOCKING_FAIL || result.tag === RESULT_TAG.REFUSED;
}
```

- [ ] **Step 3: Implement an opaque WeakMap-backed intake**

Use module-private `WeakMap` storage and frozen handles:

```js
export function createUnsafeObservationIntake({ maxBytes }) {
  if (!Number.isSafeInteger(maxBytes) || maxBytes < 1 || maxBytes > 67_108_864) {
    throw new RangeError("maxBytes must be a bounded positive safe integer");
  }
  const unsafe = new WeakMap();

  function capture(bytes, origin) {
    if (!Buffer.isBuffer(bytes) && !(bytes instanceof Uint8Array)) {
      throw new TypeError("boundary input must be bytes");
    }
    const copy = Buffer.from(bytes);
    if (copy.byteLength > maxBytes) throw new RangeError("boundary bytes exceed the admitted limit");
    if (typeof origin !== "string" || origin.length === 0) throw new TypeError("origin is required");
    const handle = Object.freeze(Object.create(null));
    unsafe.set(handle, Object.freeze({ bytes: copy, origin, transforms: Object.freeze([]) }));
    return handle;
  }

  function derive(handle, transformId, transform) {
    const state = unsafe.get(handle);
    if (!state) throw new TypeError("unsafe handle is foreign or forged");
    if (typeof transformId !== "string" || transformId.length === 0 || typeof transform !== "function") {
      throw new TypeError("derived transform requires an identity and function");
    }
    const derived = transform(Buffer.from(state.bytes));
    if (!Buffer.isBuffer(derived)) throw new TypeError("unsafe transform must return a Buffer");
    const next = capture(derived, state.origin);
    unsafe.set(next, Object.freeze({
      bytes: Buffer.from(derived),
      origin: state.origin,
      transforms: Object.freeze([...state.transforms, transformId]),
    }));
    return next;
  }
```

`stateOf(handle)` returns `"boundary-untrusted"` only when the handle is in the
private WeakMap and `"foreign"` for every copied or forged value.
`validate(handle)` must decode with `new TextDecoder("utf-8", { fatal: true })`,
parse JSON, check the exact analyzer schema, reject keys/tags/coordinate fields
that express authority-positive state, and return a recursively frozen
candidate without exposing the original bytes. Detail text is data, never
authority, and is not upgraded by containing words such as `pass` or `allow`.

```js
function canonicalValue(value, state = { nodes: 0 }, depth = 0) {
  state.nodes += 1;
  if (state.nodes > 4096 || depth > 64) throw new RangeError("canonical state exceeds structural bounds");
  if (value === null || value === undefined) throw new TypeError("canonical state forbids absence sentinels");
  if (typeof value === "boolean" || typeof value === "string") return value;
  if (typeof value === "number") {
    if (!Number.isSafeInteger(value)) throw new TypeError("canonical numbers must be safe integers");
    return value;
  }
  if (Array.isArray(value)) {
    if (Object.getPrototypeOf(value) !== Array.prototype) throw new TypeError("canonical arrays require the standard prototype");
    const descriptors = Object.getOwnPropertyDescriptors(value);
    const keys = Reflect.ownKeys(descriptors);
    if (keys.some((key) => typeof key !== "string") || keys.length !== value.length + 1) {
      throw new TypeError("canonical arrays cannot contain holes or surplus fields");
    }
    const result = [];
    for (let index = 0; index < value.length; index += 1) {
      const descriptor = descriptors[String(index)];
      if (!descriptor || descriptor.enumerable !== true || !("value" in descriptor)
          || descriptor.get !== undefined || descriptor.set !== undefined) {
        throw new TypeError("canonical array entries must be ordinary data fields");
      }
      result.push(canonicalValue(descriptor.value, state, depth + 1));
    }
    return result;
  }
  if (typeof value !== "object" || utilTypes.isProxy(value)
      || Object.getPrototypeOf(value) !== Object.prototype) {
    throw new TypeError("canonical records must be ordinary exact objects");
  }
  const descriptors = Object.getOwnPropertyDescriptors(value);
  const keys = Reflect.ownKeys(descriptors);
  if (keys.some((key) => typeof key !== "string")) throw new TypeError("canonical records cannot contain symbol keys");
  const result = {};
  for (const key of keys.map(String).sort()) {
    const descriptor = descriptors[key];
    if (!descriptor || descriptor.enumerable !== true || !("value" in descriptor)
        || descriptor.get !== undefined || descriptor.set !== undefined) {
      throw new TypeError("canonical record fields must be ordinary enumerable data fields");
    }
    result[key] = canonicalValue(descriptor.value, state, depth + 1);
  }
  return result;
}

function canonicalJson(value) {
  return JSON.stringify(canonicalValue(value));
}

function framedDigest(domain, value) {
  const canonical = canonicalJson(value);
  return `sha256:${createHash("sha256")
    .update(`${domain.length}:${domain}${Buffer.byteLength(canonical)}:${canonical}`, "utf8")
    .digest("hex")}`;
}
```
