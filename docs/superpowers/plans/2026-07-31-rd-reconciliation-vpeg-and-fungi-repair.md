## Stop conditions

Stop and ask the owner only if a decision would disclose private custody
material, overwrite unrelated work, change a published language contract
without an evidence-compatible migration, or grant production authority that
the current owner direction has not already authorized. A difficult
implementation or a red test is not by itself a blocker.
