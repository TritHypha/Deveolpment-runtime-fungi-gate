contracts, normalization helper and initial active-registry mutations without
narrowing host values or effects.

**Architecture:** Erased types are recorded as scope, not executable work.
Executable normalization and registry methods remain TypeScript unless one
Fungi/SLIDE boundary preserves open host values, optional strings, callback and
timer capabilities, mutable map identity, chaining and JavaScript failure
semantics.

evidence, Myco, private Fungi skills and Markdown slice receipts.

## Global constraints

- Local commits only; never push.
- No placeholder Fungi, host-precomputed health verdict or narrowed input.
- Preserve `unknown`, `null` refusal, binary64 timeout validation, callback
  identity, replacement semantics, mutable registry state and `this` chaining.
- New Fungi may not use `null`, `NaN`, `else if`, `throw`, `try/catch`, `for`
  or unbounded `loop`.
- Repository closure remains `UNKNOWN`; crash-linked aggregate lanes stay
  excluded.
