## Evidence and close rules

1. Pin the full Git commit and SHA-256 of every source. Use codebase-memory
   first for symbols and call paths; when its indexed build point cannot be
   independently proved, label graph freshness `UNKNOWN` and reconcile exact
   source/test reads plus bounded Myco results.
2. Run focused package tests and inspect exact consumers and package-owned
   Fungi, GIR, physical `.slide`, independent re-admission and VOK evidence.
3. Classify erased aliases/interfaces as `NO_RUNTIME_BEHAVIOR`; create no
   placeholder Fungi. Runtime constants and functions require complete source
   semantics, bounded work and the exact physical profile before a candidate.
4. Preserve JS property, collection, coercion, mutation, diagnostic and report
   behavior. A missing diagnostic never proves that a prerequisite check ran.
5. Review both private Fungi skills at every slice. Update only for a reusable
   rule absent from their current authorities; keep all skill changes private
   and unpushed.
6. At Slice 347 update the live register, TODO, roadmap and subway, then run the
   individual owner matrix. Do not run crash-linked aggregate lanes;
   repository-wide closure remains `UNKNOWN`.

`isServerOnlyImport` is not recounted: Slice 39 already governs that exact JS
target symbol. This wave may strengthen its evidence but gives it zero new
queue credit and creates no duplicate receipt.
