SLIDE inspection proved that the checked-Fungi `Int` boundary is currently
physical i32, while the TypeScript source accepts safe integers through
`2^53 - 1`. A narrower i32 proof would have silently reduced the source
domain. The JSON candidate therefore remains `BLOCKED` until a separately
reviewed typed `Int64` SLIDE/VOK boundary can admit and independently verify
the required edge values. No JSON Fungi source was created.

whole files while the evidence frequently proves one private symbol. Queue
schema v2 now distinguishes `WHOLE_FILE` from exact `SYMBOLS` scope, preserves
the file denominator, refuses malformed or widened scopes and keeps unproved
siblings blocked.

The replacement candidate is `cli.ts#mark`, whose complete source domain is
two Boolean values and whose result is an exact Unicode String. It is
classified `PARALLEL_PURE`; this classification does not extend to
