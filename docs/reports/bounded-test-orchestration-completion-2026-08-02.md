# Bounded test orchestration completion

Date: 2026-08-02

Status: repository-local control complete; no production or release authority

## Outcome

Galerina no longer starts a full phase-close from the Claude Stop hook. Root
verification is explicit, one root suite may own a checkout at a time, standard
Node test packages receive a maximum four-file worker ceiling, and every child
command runs inside an owned process tree. Unknown ownership, an invalid lease,
timeout without acknowledged tree closure, excess captured output, or a missing
verified Windows warden fails closed.

The post-fix phase-close passed **86/86** blocking gates in **544 seconds**.
The separately exercised core aggregate passed **4/4 packages** and
**5,918/5,918 tests**. During the compiler's subprocess-heavy portion the host
contained 22 Node processes; that population fell as the package completed and
returned to the single pre-existing Node process after the suite. This is a
bounded test burst, not the earlier cross-package accumulation.

## Implemented controls

| Control | Current implementation | Refusal rule |
|---|---|---|
| Root-suite exclusion | Atomic canonical-checkout lease with 256-bit nonce | A second root suite, malformed record or wrong checkout refuses before a package starts |
| Nested aggregate | Exact owner PID, nonce, checkout digest and verified supervisor-parent binding | Copied nonce, wrong owner, wrong supervisor or missing record refuses |
| Test-file workers | Default and maximum `--test-concurrency=4`; callers may choose 1-4 | Zero, malformed, fractional or greater-than-four values refuse |
| Stop hook | Child-free lease/status heartbeat | It cannot invoke `run-phase-close` or `run-all-tests` |
| Windows containment | Zero-dependency Rust Job Object warden with `KILL_ON_JOB_CLOSE`, suspended-create, assign-before-resume and owner monitoring | Missing/mismatched build receipt, setup failure or unacknowledged timeout closure refuses |
| Linux/macOS containment | Dedicated process group with bounded TERM/KILL escalation | Failed group signalling is surfaced as cleanup refusal |
| Progress | Package and phase-close start/end heartbeats on stderr | Quiet buffered output is never documented as proof of health |
| Evidence | JSON records concurrency and per-child process ownership/cleanup facts | A zero exit without a parseable non-zero test count is not a package pass |

The Windows warden source, manifest, lockfile and executable are independently
SHA-256 bound by the local build receipt. The executable is generated under the
ignored build tree; source changes invalidate the receipt until an explicit
rebuild succeeds.

## Defects found during verification

The first broad run safely returned **83/86**, exposing three real defects:

1. the process warden correctly interposed between phase-close and the nested
   core aggregate, but the lease admitted direct parentage only;
2. the project graph had not yet indexed the new runner and warden files; and
3. the code index had the same generated-evidence drift.

The lease now authenticates both the original owner and the exact supervisor
PID installed by the verified process boundary. A dedicated integration test
crosses the real Windows Job Object before admitting an inherited lease.
Graphs and indexes were regenerated by their owning tools and then checked
without writes.
